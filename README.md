# RamBabu — Birthday Film

A responsive, cinematic birthday surprise website built with plain HTML, CSS and JavaScript. It works on GitHub Pages and does not require a build step.

## Add personal photos and music

Create a folder named `assets` in the repository and upload these files with these exact names:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `birthday-song.mp3`

The photo slots stay styled placeholders until matching image files are uploaded. The music button starts playback after the visitor taps it, because mobile browsers normally block autoplay with sound.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. After deployment completes, the site should be available at:
   https://shalem046-cyber.github.io/dilepannabirth/

The site can be edited by changing `index.html`.
